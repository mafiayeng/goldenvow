# GoldenVow – Fundraising Platform

A complete fundraising platform for dowry, burial, medical, education, and harambee events.

## Features
- 🏦 Multi-event fundraising platform
- 👑 Super Admin controls everything
- 💰 Fee earnings with referral tiers (2% → 1.54%)
- 💬 Real-time chat (public and private)
- 📱 Mobile-first design
- 🔒 Maintenance mode with custom messages
- 📊 Analytics dashboard
- 💡 Feature suggestions from contributors
- 📄 PDF receipt generation

## Deployment
1. Set environment variables
2. Deploy on Render/Heroku
3. First user with SUPER_ADMIN_SECRET becomes super admin
