📖 GoldenVow – Complete Admin Guide

Everything you need to know about managing your fundraising platform.

👑 1. Roles & Responsibilities

Super Admin (You)
  • ✅ Earns 2% platform fee from EVERY contribution across ALL events
  • ✅ Approves or rejects withdrawal requests from all admins
  • ✅ Manages admins – enable, disable, or delete admin accounts
  • ✅ Locks/unlocks events – marks fee as paid to unlock events
  • ✅ System settings – maintenance mode, custom messages
  • ✅ Feature requests – reviews and responds to all suggestions
  • ✅ Contact messages – reads and replies to all messages
  • ❌ Cannot approve contributions – that's the Admin's job
🧑‍💼 Admins
  • ✅ Create and manage events
  • ✅ Approve/decline contributions from contributors
  • ✅ Verify payment proofs – check screenshots and approve
  • ✅ Chat with contributors privately
  • ✅ Request withdrawal of their own money (the pledge amounts)
  • ❌ Cannot withdraw the 2% fee – that goes to Super Admin
  • ❌ Cannot manage other admins – only Super Admin can
👤 Contributors
  • ✅ Register with username and password
  • ✅ Login to view their own contributions
  • ✅ Submit payment proof – upload screenshots
  • ✅ Chat with admins privately
  • ✅ Download receipts – only after 7 days (admins can download anytime)
  • ✅ Suggest features – share ideas to improve the platform
  • ❌ Cannot see other contributors' payments – only their own

💰 2. Complete Money Flow

  1. Contributor pledges – They promise to send a certain amount.
  2. Contributor sends money – They send the actual amount to the admin's account (Paybill, M-Pesa, or Bank).
  3. Contributor uploads proof – They upload a screenshot of the payment.
  4. System auto-verifies – The system compares the sender name (from the screenshot) with the Account Name set by the admin.
  5. Admin reviews and approves – Admin checks the screenshot and clicks "Approve".
  6. System deducts 2% fee – This fee goes to the Super Admin.
  7. Admin gets the full amount – Admin receives the full pledge amount from the contributor.
  8. Super Admin accumulates fees – All 2% fees from ALL events go to Super Admin.
  9. Super Admin withdraws – When fees reach KES 50+, Super Admin can withdraw.

⚙️ 3. Creating an Event

Step-by-Step:
  1. Go to Dashboard → New Event
  2. Select Event Type – Dowry, Burial, Medical, Education, Harambee, or Other
  3. Enter Event Title and Description
  4. Set Target Amount – your fundraising goal
  5. Set Event Date and Deadline
  6. ⭐ IMPORTANT: Enter the Account Name – this is the name contributors will send money to
  7. Add Payment Details – Paybill, M-Pesa number, Bank details, etc.
  8. Optionally enable Grace Period – gives extra time for fee payment
  9. Click Create Event
⚠️ Account Name is Critical!
If you set Account Name as "Alex Kiprop", contributors will see "Send money to: Alex Kiprop". The system will auto-verify if the sender name matches.

👥 4. Managing Contributors

How the System Handles Contributions:
  1. Contributor registers – They create an account with username and password
  2. Contributor pledges – They enter their pledge amount
  3. Contributor sends money – They send money to the Account Name you provided
  4. Contributor uploads proof – They upload a screenshot of the payment
  5. System auto-verifies – ✅ Green tick if sender name matches Account Name
  6. Admin reviews – Check the screenshot to confirm the money was sent
  7. Admin approves – Click "Approve" and enter the actual amount received
  8. Contribution is approved – Status changes to "Approved"
✅ Name Match System auto-verified
❌ Name Mismatch Admin must review manually

💰 5. Fees & Earnings

Platform Fee (2%)
  • Who earns it: Super Admin (You)
  • How it's calculated: 2% of the ACTUAL amount received (not the pledge)
  • Example: If contributor sends KES 800, fee = 2% × 800 = KES 16
  • Minimum withdrawal: Fees must reach KES 50 before you can withdraw

🔒 6. Event Locking

When Does an Event Lock?
  • Condition 1: The total fee for the event reaches KES 50 or more
  • Condition 2: 3 days have passed since the first contribution
  • Condition 3: The fee has NOT been paid
When Locked, NO ONE can access the event!
Not even the admin! Only the "Contact Super Admin to Pay Fee" page is visible.
How to Unlock an Event
  1. Admin pays the fee to Super Admin (outside the system)
  2. Admin clicks "Request Unlock" on the locked event page
  3. Super Admin gets notified and goes to Super Dashboard
  4. Super Admin clicks "Mark Paid" on the event
  5. Event is unlocked! Everyone can access it again

📤 7. Withdrawals

For Admins
  • Admins can request withdrawal of their own money
  • They click "Request Withdrawal" on their dashboard
  • Super Admin approves and pays them
For Super Admin (You)
  • You earn 2% from ALL events
  • You can withdraw when fees reach KES 50+
  • Go to Super Dashboard → Request Withdrawal
  • You approve your own withdrawal
Minimum Withdrawal: KES 50 (standard M-Pesa minimum)

📄 8. Receipts

  • Contributors: Can download receipt only after 7 days of approval
  • Admins: Can download any receipt anytime
  • Why 7 days? Gives time for verification and prevents abuse

💬 9. Chat

Public Chat
  • On the event landing page
  • Anyone can send messages
  • Shown to all visitors
Private Chat
  • 1-on-1 between admin and contributor
  • Admins: Go to "Chat" tab in navbar
  • Contributors: Click "Chat with Admin" on their view page

💡 10. Feature Requests

  • Contributors can suggest new features from any event page
  • Super Admin can view, approve, or decline suggestions
  • Go to Super Dashboard → Manage Feature Requests

🛠️ 11. Maintenance Mode

  • Super Admin only can enable maintenance mode
  • Go to Settings → Toggle Maintenance Mode
  • Add a custom message and estimated return time
  • Super Admin can still access the system during maintenance
